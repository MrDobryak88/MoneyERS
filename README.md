Приложение для обмена валют

Обзор
Современное приложение на Python для автоматизации работы пунктов обмена валют в Дагестане. Поддерживает аутентификацию пользователей, конвертацию валют, учет транзакций, аналитику и настройки с учетом локальных особенностей.
Установка

Склонируйте репозиторий или скачайте файлы проекта.
Установите Python (рекомендуется версия 3.8+).
Создайте виртуальное окружение (опционально, но рекомендуется):python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

Установите зависимости:pip install -r requirements.txt

Создайте папку plots для графиков:mkdir plots

Запустите приложение:python main.py

Сборка в .exe

Установите PyInstaller:pip install pyinstaller

Выполните команду в директории проекта:pyinstaller --onefile --windowed --add-data "plots;plots" main.py

Файл .exe будет в папке dist/.

Примечания

Приложение использует локальную базу данных SQLite (exchange.db) для хранения транзакций и настроек.
Курсы валют загружаются из API Центрального банка России. При отсутствии интернета используются локальные данные из rates.json.
Создайте папку plots/ для сохранения графиков.
Зарегистрируйтесь или войдите для доступа к функциям.
